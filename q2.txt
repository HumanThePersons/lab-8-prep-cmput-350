Question 2.2
We could store the unique vertices in an array - which in the case of a quad are just the corners. In the example from question 2.1 that would be [(200, 150), (600,150), (200, 450), (600, 450)].
Then, each triangle would be found as the indexes of the three vertices that make it up, so triangle 1 from above would be [2, 1, 0] and triangle 2 would be [2, 3, 1].

- The original method from 2.1 uses 6 vertices * 2 values each (x and y) * 4 bytes each (floats) which is 48 bytes total.
- The new method uses 4 vertices * 2 values each * 4 bytes each which is 32 bytes, plus 3 floats for each triangle, which is 6 floats * 4 bytes each = 24 bytes. In total, this comes to 32 + 24 =     56 bytes.
- So, for data of a smaller size (floats - 4 bytes each) it is more beneficial to use the first method, however using doubles we get:

- Original method: 6 * 2 * 8 = 96 bytes
- New method: 4 * 2 * 8 + 6 * 4 = 64 + 24 = 88 bytes
- So, when data sizes get bigger, it can be more efficient to use the index buffer method instead.

- Plus, more complex images may have many more overlapping vertices, so the index buffer method would be more beneficial to reduce memory usage.
